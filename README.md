# 月影とび

長押しで力を溜め、離して跳ぶ。宵闇に浮かぶ**石の飛び石**を渡り、何段先まで届くかを競うブラウザゲームです。
インストール不要・スマホ縦持ちでそのまま遊べます。

**▶ [遊ぶ](https://hirohgxx.github.io/tsukikage-tobi/)**

- 画面を**長押し**して力を溜め、**離す**と跳びます。溜めが長いほど遠くへ。
- 台座の**中央に着地すると「会心」**。会心が続くほど記録が伸びます。
- 台座を外したら夜明け（おしまい）。**50段で満月成就**、その先も記録は伸ばせます。
- **4段ごとに跳ぶ御霊が交代**します（30体を巡回。並びは一夜ごとに変わります）。
- **8段ごとに天候が変わります**。月夜（いつも通り）・追い風（伸びすぎる）・雨（伸びない）——同じ溜めでも飛び方が変わります。

## 開発

```
python3 scripts/build-chars.py   # 公式ちびシートから src/chars.js を生成
node scripts/build-dist.js       # src/ → index.html（単一HTML）
NODE_PATH=../shikifuda-kasane/node_modules node scripts/playtest.js   # 通し検証
```

### 試しモード（テストモード）

タイトルの**題字「月影とび」を1.5秒以内に3回タップ**すると出入りできる（入ると誉れの欄が「試し」表示に変わる）。画面下にボタン列が出る。

| ボタン | すること |
|---|---|
| 天候 | 月夜 → 追い風 → 雨 と手で切り替える |
| +10段 | 10段進める（節目・交代・月の満ち欠けも追従する） |
| 御霊 | 次の御霊のカットインを出す |
| 声 | 栞の台詞を順に鳴らす（開始→結果6種） |
| 不死 入/切 | 外しても落ちないようにする（既定は「入」） |

**試しモードの記録は保存しない**（式札かさねで稽古モードがBESTを汚した件の再発防止）。

デバッグ用ハッシュ: `#autoperfect`（自動で会心を出し続ける）／`#automiss`（わざと外す）／`#autoskip`（台座の一つ飛ばしを狙う）／`#wx0`〜`#wx2`（天候を固定: 月夜・追い風・雨）／`#stat`（押下時間と着地のずれを記録）／`nofloat`（撮影用）。
